# 使用前请阅读此文件

完整源码来自没有逐日 Git 历史的本地压缩包；开发月份为作者回忆的 2026 年 9 月。`main` 是实际于 2026-10-14 按模块依赖顺序重建的 30 天快照；Git 作者日期与提交者日期使用 2026-09-01 至 2026-09-30 的重建日程。原来的真实导入记录（含 9 月 20 日组件提交）保存在 `codex/original-import-20261014` 分支。

## 使用前

1. 在本目录及自己的隔离 Python 环境中执行 `python -m pip install -r requirements.txt`。复制 `conf/config.example.ini` 到 `conf/config.ini`，填写自己的配置，并设置 `export API_TEST_CONFIG_FILE="$PWD/conf/config.ini"`；真实配置文件已加入忽略规则。
2. 用 `environment.example.xml` 和 `extract.example.yaml` 了解字段结构。`extract.yaml` 是运行时状态，应由本地运行生成并被忽略。
3. `data/` 与 `testcase/` 中的请求、断言、变量和数据结构保留了原项目的测试足迹，但值已经换成合成样例。需要接入真实系统时，请在本地配置，不要提交业务数据。
4. 钉钉、邮件、Jenkins 集成默认关闭；必须显式设置相应 opt-in 环境变量后才允许调用。

测试需要用户自己的 API、数据库和相关外部服务；没有这些服务时，测试可能失败或无法完成初始化。本说明不把静态检查写成业务运行结果。

## 模块说明

- `base/` 负责请求用例执行、响应抽取和 GUI 用例生成。
- `common/` 提供请求发送、断言、日志、数据读写和可选连接器。
- `conf/` 提供环境设置与配置读取。
- `testcase/` 保留业务场景、产品管理和单接口测试源码。

## 证据边界

导入前只做 Python AST 静态语法检查和 YAML/XML/INI 静态解析。没有运行 pytest、请求接口、连接数据库或 SSH、访问 Jenkins，也没有验证业务结果。
